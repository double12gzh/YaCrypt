## 事实与根因

1. 原问题：CI/hook/pre-commit/release 分别维护 Cargo 命令，默认根 package 的测试不覆盖成员单测。
   临时真实 workspace 证明旧命令退出 0；统一入口命中成员断言；修正夹具后通过。
   再将统一入口中的 --workspace 去掉，新回归确实失败，验证它有检测能力。
2. 首轮自己的流程测试存在隔离漏洞：临时目录并不能隔离 Git 全局 hooksPath / GIT_*。
   独立验收用模拟外部配置实际复现；实现会话修正环境，并增加外部文件不变的回归检查。
3. hook 内容相同不等于可执行；补齐执行位恢复及测试。
4. 技能相对链接计算错误；链接解析发现并修正，最终检查所有新增文档的本地链接。

## 写回

- scripts/verify.sh 成为完整门禁的唯一来源；所有完整入口引用它。
- scripts/test_verify.py 验证成员失败、阶段中止、入口接线、worktree hook 和外部 Git 状态隔离。
- LESSONS 新增 Git fixture 隔离与 hook 可执行性的教训；不把一次事件伪称多次复发。
- 子系统文档区分实际保证与限制：同步写入不是原子替换，回滚是尽力操作，TUI 初始化早退有独立路径。
