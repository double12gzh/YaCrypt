## 目标与非目标

触发：成员 crate 的单测失败。旧默认根包检查可能通过；统一门禁必须失败。
所有完整入口调用同一脚本，失败即停止，不依赖调用目录，不清理构建产物。
不改变密码学、CLI/TUI 用户行为、依赖版本、发布权限或自动调度。
分项 Make 命令保留为调试工具，make all 改为完整门禁。

## 验收

1. 临时真实 Cargo workspace 中，根包通过、成员单测失败：旧命令退出 0，新入口非零且命中该断言。
2. 恢复成员正确行为后新入口通过；其他阶段用明确标注的替身隔离测试调度。
3. 任一阶段失败不继续后续阶段；所有入口接线检查通过。
4. 临时 Git linked worktree 可安装并执行 hook；已有用户 hook 保持原内容。
5. YaCrypt 本体完整门禁：记录真实运行结果与工具版本，失败不得伪装通过。
6. 独立验收审查当前提交和文档链接，复盘写回实际发现。
