# YC-008：Apple Python 缺少 waitid 的启动修复

来源：用户运行 watch 的截图；base 272d5c0。目标：相同命令在本机 Apple Python 3.9.6 下正确启动，不削弱 PID 保留及进程组清理。范围为 CLI 启动、能力检测、测试和契约。不改全局解释器，不安装依赖，不修改模型路由。

验收：真实 /usr/bin/python3 复现缺 API；能力不足时在台账操作前选择已安装解释器，保持参数及子进程 PATH；无兼容解释器清晰失败；真实 watch 单轮返回 idle；完整门禁及独立验收。

独立验收 PASS：见 [报告与源文件哈希](evidence/YC-008/independent-review.json)。真实 Apple Python 单轮 watch 退出 0、idle/0；无兼容候选在 Ledger 前返回结构化错误。验收中修正了相对 PATH 在后续 gate 切换 cwd 后失效的问题，测试改用相对候选并验证绝对 PATH。

复盘：先前只在 Homebrew Python 上验证，遗漏用户终端默认解释器的 API 能力差异。现在在台账访问前处理缺失能力，不使用 poll/wait 降级监督；不修改用户全局配置。本次无需模型调用演练，因为故障发生于模型派工之前。

最终完整门禁 PASS：58 项 Python 回归、59 项 Rust 测试，以及 fmt/clippy/build/deny；日志与哈希在 evidence/YC-008。
