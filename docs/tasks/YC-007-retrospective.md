# YC-007：真实多模型闭环复盘

本轮将 pi/omp 接入统一进程监督与任务台账，并实现固定探针发现、候选去重、有限派工、独立验收、候选集成及 Git 复盘写回。入口和使用方式见 [自进化说明](../evolution.md)。

## 发现与实现

探针在临时 Git 仓库将 tracked file 替换为 directory，得到提交前后不一致的摘要；它发现的是既有实现缺陷，不是为演练人为引入的新 bug。
pi 修复摘要逻辑，使非符号链接的目录索引项不参与摘要，但继续哈希叶节点和符号链接目标。新增测试覆盖提交/暂存稳定、成功 submit、后续子文件修改拒绝、目录/文件/悬空符号链接重定向拒绝。
新回归在旧实现上产生两项行为失败，见 [旧代码反证](evidence/YC-007/regression-on-old-code.log.gz)。

## 停止与恢复记录

1. 初始分组 Gemini 探测返回显式 DeepSeek responseModel；只发送了固定探测语句。经用户批准改用明确路由，协议检查拒绝显式模型冲突。
2. 第一代任务的 pi 输出在 agent_end 后有合法 agent_settled；旧解析器拒绝，失败证据没有改成成功。支持该终止协议后显式 reconcile，新一代任务重新执行。旧草稿按原字节压缩归档。
3. 第二代任务已提交并通过门禁，但 omp 将非阻塞建议及只读测试限制列为 ISSUES，循环自动停止。协调器核对具体意见，显式追加一次相同提交复核，保留首轮结论；不是后台无限重试，也没有手填 PASS。

控制器另一次 omp 审查提出 Path / Path 非法、应复用作者和集成目录等错误判断。原始 BLOCKED 报告保留，通过可复现测试和独立 agy/Claude 复核处理，而非按模型投票裁决。超时审查也保留，不计为通过。

独立 Claude 还发现延迟复核会在完整门禁后才因原租约过期失败。现已提前检查租约必须覆盖门禁及余量，并增加过期时不跑门禁/模型、不修改日志的回归；不自动复活过期令牌。

## 能力边界

默认一轮一个候选、两个模型会话；显式复核额外计一次。固定发现器仅覆盖该快照不变量与文档相对链接，不具备任意产品需求发现能力；没有永久后台调度、金额/token 硬上限、自动 main 合并、push 或发布。失败停住并保存现场，租约或时间到期不会授权重试。
运行器工具限制不是 OS 文件沙箱。当前是同一用户、可信仓库的本机协作，不能包装为对恶意 agent 的安全隔离。
成功候选会提交代码和事实复盘，并从候选新版本继续扫描；人工交付与自动候选集成分别记录。

可追溯证据见 [文件哈希清单](evidence/YC-007/manifest.json) 和 [验收报告](YC-007-acceptance.md)。原始流保留本机 common Git dir；仓库只归档必要回执、最终响应、哈希与压缩门禁，不上传原始思考/工具上下文流或认证配置。
